Hexo 博客零成本部署到 Vercel 完整指南

详细记录如何将 Hexo 静态博客免费部署到 Vercel 平台的完整过程，包括自动化部署、自定义域名配置和常见问题解决方案。

为什么选择 Vercel

在众多静态网站托管平台中，Vercel 脱颖而出的原因：

  • 🆓 完全免费：个人项目无任何费用，包含 CDN 和 SSL 证书

  • 🔄 自动化 CI/CD：Git 推送即自动构建部署
  • 🌐 域名友好：免费提供 .vercel.app 域名，支持自定义域名

标准的 Hexo 项目应包含以下核心文件：

详细部署步骤

第一步：代码托管到 GitHub

1. 创建 GitHub 仓库

# 在项目根目录初始化 Git
cd your-hexo-blog
git init

# 添加远程仓库（替换为你的仓库地址）
git remote add origin https://github.com/yourusername/hexo-blog.git

2. 配置 .gitignore 文件

创建 .gitignore 文件，避免提交不必要的文件：

# Dependencies
node_modules/
npm-debug.log*
yarn-debug.log*
yarn-error.log*

# Build output
public/
.deploy*/

# Environment files
.env
.env.local
.env.*.local

# IDE files
.vscode/
.idea/
*.swp
*.swo

# OS files
.DS_Store
Thumbs.db

# Hexo cache
db.json
*.log

# Theme specific (如果主题作为子模块)
themes/*/node_modules/

3. 首次提交代码

# 添加所有文件
git add .

# 提交代码
git commit -m "Initial commit: Add Hexo blog"

# 推送到 GitHub
git push -u origin main

第二步：在 Vercel 创建项目

1. 注册登录 Vercel

访问 vercel.com 并使用 GitHub 账号登录：

  1. 点击 "Sign Up" 或 "Login"
  2. 选择 "Continue with GitHub"
  3. 授权 Vercel 访问你的 GitHub 账户

2. 导入 GitHub 项目

在 Vercel 控制台：

  1. 点击 "New Project"
  2. 选择 "Import Git Repository"
  3. 找到你的 Hexo 项目仓库
  4. 点击 "Import"

3. 配置构建设置

重要配置项：

# Framework Preset（框架预设）
Framework Preset: Other

# Build & Development Settings（构建和开发设置）
Build Command: npm run build
Output Directory: public
Install Command: npm install

# Root Directory（根目录）
Root Directory: ./（保持默认）

# Node.js Version（Node.js 版本）
Node.js Version: 18.x（推荐）

详细配置截图说明：

  1. Framework Preset: 选择 "Other" 而不是 "Hexo"（避免配置冲突）
  2. Build Command: 确保使用 npm run build 而不是默认命令
  3. Output Directory: 必须设置为 public（Hexo 生成目录）
  4. Install Command: 保持 npm install（或 yarn install）

第三步：环境变量配置

1. 必要环境变量

在 Vercel 项目设置中添加环境变量：

# 时区设置
TZ=Asia/Shanghai

# Node.js 环境
NODE_ENV=production

# 包管理器指定（可选）
NPM_CONFIG_PRODUCTION=false

2. 主题相关环境变量

如果使用了需要密钥的功能（如评论系统），添加相应环境变量：

# Algolia 搜索（如果启用）
ALGOLIA_APP_ID=your_app_id
ALGOLIA_API_KEY=your_api_key
ALGOLIA_INDEX_NAME=your_index_name

# 其他第三方服务密钥
# VALINE_APP_ID=xxx
# VALINE_APP_KEY=xxx

第二步：在 Vercel 中配置域名

1. 添加自定义域名

在 Vercel 项目设置中：

  1. 进入项目设置页面
  2. 点击 "Domains" 选项卡
  3. 输入你的域名（如 yourdomain.com）
  4. 点击 "Add"

2. 获取 DNS 配置信息

Vercel 会显示需要配置的 DNS 记录：

主域名配置：

Type: A
Name: @
Value: 76.76.19.61

www 子域名配置：

Type: CNAME
Name: www
Value: cname.vercel-dns.com

第三步：配置 DNS 解析

1. 在域名注册商处配置

以 Cloudflare 为例：

  1. 登录 Cloudflare 控制台
  2. 选择你的域名
  3. 进入 DNS 设置页面
  4. 添加以下记录：
# 主域名 A 记录
Type: A
Name: @
IPv4 address: 76.76.19.61
Proxy status: DNS only（灰色云朵）

# www 子域名 CNAME 记录
Type: CNAME
Name: www
Target: cname.vercel-dns.com
Proxy status: DNS only（灰色云朵）

2. DNS 验证和等待

配置完成后：

  • DNS 传播时间：通常 5-30 分钟
  • 全球生效时间：最多 48 小时
  • 验证命令：
# 检查 A 记录
nslookup yourdomain.com

# 检查 CNAME 记录
nslookup www.yourdomain.com

# 在线检查工具
# https://dnschecker.org/

第四步：SSL 证书自动配置

Vercel 会自动为你的域名申请和配置 SSL 证书：

  • 证书类型：Let's Encrypt 免费证书
  • 自动续期：无需手动操作
  • 配置时间：域名验证通过后 5-10 分钟

验证 HTTPS 生效：

# 检查 SSL 证书
curl -I https://yourdomain.com

# 应该返回 200 状态码和正确的响应头

自动化工作流优化

1. 创建 GitHub Actions（可选增强）

在项目根目录创建 .github/workflows/deploy.yml：

name: Deploy to Vercel

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v3

    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        cache: 'npm'

    - name: Install dependencies
      run: npm ci

    - name: Build site
      run: npm run build

    - name: Deploy to Vercel
      uses: amondnet/vercel-action@v25
      with:
        vercel-token: ${{ secrets.VERCEL_TOKEN }}
        vercel-org-id: ${{ secrets.ORG_ID }}
        vercel-project-id: ${{ secrets.PROJECT_ID }}
        working-directory: ./

2. 配置构建缓存优化

在 vercel.json 中添加构建优化配置：

{
  "version": 2,
  "builds": [
    {
      "src": "package.json",
      "use": "@vercel/static-build",
      "config": {
        "distDir": "public"
      }
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/$1"
    }
  ],
  "functions": {
    "app.js": {
      "includeFiles": "public/**"
    }
  },
  "crons": []
}

常见问题和解决方案

部署相关问题

问题 1: 构建超时

错误现象：

Error: Build timed out after 10m0s

解决方案：

  1. 优化构建脚本：
{
  "scripts": {
    "build": "hexo clean && hexo generate --silent"
  }
}
  1. 减少不必要的插件：
# _config.yml - 禁用开发时插件
plugins:
  - hexo-generator-sitemap  # 保留
  # - hexo-admin             # 移除开发插件
  1. 升级 Vercel 套餐（如需要）

问题 2: 静态资源 404

错误现象：

  • CSS/JS 文件 404
  • 图片无法加载
  • 字体文件丢失

解决方案：

  1. 检查 URL 配置：
# _config.yml
url: https://yourdomain.com  # 不要有尾斜杠
root: /
  1. 确认资源路径：
# 主题配置文件中
CDN:
  enable: false  # 避免 CDN 路径冲突
  1. 检查 .gitignore：

确保静态资源文件被正确提交

问题 3: 主题样式异常

错误现象：

  • 页面布局错乱
  • 主题特色功能失效
  • 自定义样式不生效

解决方案：

  1. 主题文件完整性检查：
# 确保主题文件完整
ls -la themes/your-theme/
# 应包含 source、layout、_config.yml 等目录
  1. 依赖安装检查：
# 安装主题依赖
cd themes/your-theme
npm install  # 如果主题有 package.json
  1. 配置文件同步：
# 确保主题配置正确
theme: anzhiyu  # 主题名称

排查步骤：

  1. DNS 检查：
# 检查 A 记录
dig yourdomain.com A

# 检查 CNAME 记录
dig www.yourdomain.com CNAME

# 应该指向 Vercel 的 IP 或 CNAME
  1. DNS 传播检查：

使用在线工具：https://dnschecker.org/

  1. Cloudflare 用户特别注意：
Proxy Status: DNS only (灰色云朵)
不要开启代理（橙色云朵）

问题 2: SSL 证书问题

错误现象：

NET::ERR_CERT_AUTHORITY_INVALID
Your connection is not private

解决方案：

  1. 等待证书生成：首次配置需 10-30 分钟
  2. 检查域名验证：确保 DNS 解析正确
  3. 强制刷新：清除浏览器缓存和 DNS 缓存
# 清除 DNS 缓存 (Windows)
ipconfig /flushdns

# 清除 DNS 缓存 (macOS)
sudo dscacheutil -flushcache
