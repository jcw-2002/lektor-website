    lektor 操作

    Quick start

    安装库：

    pip install lektor

    初始化：

    lektor quickstart

    启动服务：

    lektor server
uv run lektor server -f webpack

    MD写作格式

    创建 contents.lr 文件

    title: 我的第一篇博客文章
---
pub_date: 2026-08-21
---
author: jcw
---
body:

这里就是写 Markdown 的地方！

## 一级标题
你可以直接把原本 `.md` 文件里的内容整篇复制粘贴到这里。

* 支持列表
* 支持代码块
* 支持图片与公式

    方法一：文章专属图片（最推荐、最整洁 ⭐）

    Lektor 最强大的特性之一是附件机制（Attachments），你可以把图片直接和文章放在同一个文件夹里，方便统一管理。

    1. 放置图片

    把你的图片（例如 pic.png）直接放到该文章的目录下：

    blog/
└── test/
    ├── contents.lr
    └── pic.png       <-- 直接把图片扔到这里

    2. 在 Markdown 中引用

    在 contents.lr 的 body 区域直接用标准 Markdown 语法写图片名即可（无需写复杂的绝对路径）：

    body:

这是我的文章正文。

![图片描述](pic.png)

    💡 在后台操作更简单： 如果你在浏览器后台 http://localhost:5000/admin 里编辑文章，页面下方有一个 Attachments（附件） 区域，你可以直接把图片拖拽上传进去，然后在编辑框里写 描述 即可。

    方法二：全局公共图片（如头像、公共插图）

    如果你有一些所有文章都会用到的公共图片（比如 Logo、博客头像）：

    1. 放置图片

    放到项目根目录的 assets/ 文件夹下（例如 assets/images/）：

    你的项目根目录/
├── assets/
│   └── images/
│       └── logo.png  <-- 放在这里
├── content/
└── ...

    2. 在 Markdown 中引用

    使用以 / 开头的绝对路径：

    body:
![站点Logo](/images/logo.png)

    方法三：使用外部网络图片（图床）

    如果你使用的是网络上的图片链接或自己搭建的图床，直接使用完整的 HTTP/HTTPS 链接即可：

    body:
![网络图片](https://example.com/images/sample.jpg)
